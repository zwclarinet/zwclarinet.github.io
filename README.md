# Zhen Wang - Personal Website

Welcome to my personal website! This is a Jekyll-based website showcasing my work as a performer and creative professional.

## About This Website

This website is built using the Jekyll static site generator and features:

- **Home Page**: Welcome message and introduction
- **Blog**: Performance experience posts and insights
- **About**: Personal information and background
- **Media**: Video content and media gallery
- **Contact**: Contact information and form

## Features

- Responsive design that works on all devices
- Dark/light mode toggle
- Blog with pagination
- Contact form integration
- YouTube video embedding
- Professional portfolio layout

## Getting Started

### Prerequisites

- Ruby 2.5 or higher
- Jekyll 4.0 or higher
- Bundler

### Installation

1. Clone this repository
2. Install dependencies: `bundle install`
3. Run locally: `bundle exec jekyll serve`
4. Visit `http://localhost:4000`

### Deployment

This website can be deployed to:
- GitHub Pages
- Netlify
- Any static hosting service

## Customization

- Update personal information in the page files
- Modify colors and fonts in `_config.yml`
- Add new blog posts in the `blog/` directory
- Update navigation in `_data/menu.yml`
